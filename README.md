Why do you need the  runFullTrust  capability, and how will it be used in your product?*

> This Python Tkinter desktop application is packaged using PyInstaller. It requires runFullTrust to operate as a traditional Windows desktop application, launch and manage local Python processes, and run a local web application on port 8765. It also checks port availability to prevent conflicts. All operations support the application's intended functionality and does not interfere with Windows security settings or compromise system and user safety.
